# Security

This tool reads a mailbox that contains invoices and sends mail on its behalf, so we take reports seriously.

Please do not open a public issue for a vulnerability. Use **Security > Report a vulnerability** on this
repository (a private GitHub security advisory) instead. Include what you found, how to reproduce it and what
an attacker could do with it. You can expect a first response within a few working days.

Supported version: the latest commit on `main`.
